Admin setup

Generates the config.js file for the admin page. Run once (or whenever you rotate the token or password). Nothing here is sent anywhere — it all happens in this browser.

Needs Contents: read & write and Actions: read & write, scoped to this repo only.

Everyone who administers the calendar will use this password. Choose a long one (a passphrase of 4+ random words is ideal) — it is the only thing protecting the token.
